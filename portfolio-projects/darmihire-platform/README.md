# DarmiHire

**Modern hiring, powered by AI.**

DarmiHire is an AI-powered recruitment and Applicant Tracking System
developed by Darmi Solutions.

## Technology Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

### Backend
- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL
- Flyway

### Infrastructure
- Docker
- Docker Compose
